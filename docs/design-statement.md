# Design Statement

The Glitching Archive is a speculative WebAR museum prototype for political ceramic mugs from a stored collection. It treats the mug as both a daily object and a political memory container: something held, washed, stored, joked with, argued over, and eventually catalogued.

The central interaction is a pour. A visitor scans a mug marker or opens the no-AR object page, then tilts or slides from `surface` to `middle` to `core`. Each layer changes the kind of truth the interface is allowed to claim. Surface holds object facts and known metadata. Middle holds labelled inference and speculation. Core holds redaction, unresolved memory, dispute, and local visitor contribution.

The installation is intentionally more than a phone screen. The physical cup, printed QR or AR marker, handheld route, and projection wall create a small archive system in the room. The visitor can read privately on the phone, then see fragments and local contributions spill outward into public wall mode.

The project uses right-to-opacity as a design principle. Missing ownership, sensitive political affiliation, uncertain harm context, or contested memory should not be forced into a confident museum story. Redaction remains visible so absence can be read as part of the archive rather than as a defect to hide.

The current prototype uses placeholder mug records and placeholder asset paths. It demonstrates interaction, ethics, and installation structure; it does not claim verified historical metadata until source records, photographs, object labels, and rights information are supplied.
