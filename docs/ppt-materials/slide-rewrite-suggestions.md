# Slide Rewrite Suggestions

## Updated Title Slide Copy

The Glitching Archive  
A camera gesture museum prototype for political ceramic mugs.

Subtitle option: Pouring becomes a way to move through evidence, interpretation, redaction, and visitor memory.

## Updated Design Question

How can a visitor use a simple pouring gesture to explore the political memory held by an everyday ceramic mug?

How can an archive interface show uncertainty, redaction, and speculation without turning them into false facts?

## Updated Interaction Flow

1. Choose a political mug.
2. Open camera gesture mode, or use the no-camera walkthrough.
3. Perform a hand-pouring gesture, or move the fallback slider.
4. The mug tilts as the pour value increases.
5. Surface reveals visible evidence and metadata.
6. Middle reveals labelled inference and speculation.
7. Core reveals redaction, unresolved questions, and visitor memory.

## Updated User Journey

The visitor enters through the homepage and chooses either gesture mode or the accessible no-camera route. They select a mug, pour through its layers, and read each fragment with its source status visible. If they want to contribute, they add a local question, memory, dispute, or counter-reading. The projection wall gathers these layered records for a shared installation view.

## Updated System Diagram Text

Camera or slider input -> pour value -> mug tilt + layer state -> labelled archive fragments -> optional sound/projection output.

Local contribution -> browser LocalStorage -> object page list -> projection wall visitor-memory state.

## Updated Projection Wall Text

The projection wall turns the individual phone interaction into a room-scale archive surface. It shows the same mug records across Surface, Middle, and Core, keeping fact, inference, speculation, redaction, and visitor contribution labels visible.

## Updated Ethics Text

The prototype uses source labels as an ethical interface rule. It does not convert speculation into fact, and it treats redaction as a legitimate archive state. The right to opacity means some names, harms, ownership stories, and contested memories should remain withheld until there is evidence and consent.

## Updated AI / Codex Process Note

Codex supported prototype implementation, route structure, interface copy, fallback states, and documentation. It was not used as a historical authority. Museum metadata, political context, and object matches remain placeholders or labelled interpretations unless verified by supplied sources.

## Updated Final Prototype Showcase

This prototype is now a working web-based installation system: homepage, camera gesture pour route, no-camera object walkthrough, projection wall, local contribution loop, and design statement. It is a prototype showcase rather than a finished museum database.

## Updated Final Takeaway

The Glitching Archive uses pouring as a critical interface gesture. The cup does not reveal one stable truth; it moves between visible evidence, interpreted meaning, withheld memory, and local contribution.
