# Public Archive Placeholder Paths

Place verified public assets under these folders when available:

- `images/`: object photographs.
- `markers/`: AR.js `.patt` marker files.
- `qr/`: QR codes for physical installation labels.
- `audio/`: projection or sound-wall audio loops. The layer-reactive sound wall uses
  `projection-surface.mp3`, `projection-middle.mp3`, and `projection-core.mp3`.
  See `audio/README.md` for caption placeholders and fallback behavior.
- `models/`: optional lightweight 3D mug stand-ins.

The TypeScript manifest lives in `src/data/mugs.ts`; the human handoff list lives in `docs/archive-asset-requirements.md`.
