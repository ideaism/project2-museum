# Public Archive Asset Paths

Place verified public assets under these folders when available:

- `images/`: object photographs.
- `models/`: lightweight 3D mug stand-ins.
- `audio/`: projection or sound-wall audio loops. The layer-reactive sound wall can use `projection-surface.mp3`, `projection-middle.mp3`, and `projection-core.mp3`.
- `qr/`: optional QR codes for physical labels that open `/gesture/:id` or `/object/:id`.
- `markers/`: legacy marker assets retained from the earlier AR marker prototype. These are obsolete for the current Camera Gesture Pour Experience.

The TypeScript manifest lives in `src/data/mugs.ts`; the human handoff list lives in `docs/archive-asset-requirements.md`.
