# Legacy Marker Assets

This folder is retained only for backwards compatibility with an earlier AR.js marker prototype.

The current core interaction is the Camera Gesture Pour Experience:

- `/gesture/:id`
- `/camera-test`
- `/object/:id` as the no-camera fallback

The final assessment does not require marker cards or `.patt` files. Do not use this folder as the setup guide for the current prototype.

See:

- `docs/gesture-pour-interaction.md`
- `docs/camera-troubleshooting.md`
- `docs/final-assessment-setup.md`
